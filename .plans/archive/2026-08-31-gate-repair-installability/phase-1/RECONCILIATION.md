## Conflicts adjudicated

1. **Scope of the dirty-path refusal — design-critic (D1: mutation targets only) vs exec-gates (B6: every file the suite reads).** Adopted exec-gates. Evidence: `.agents/skills/adr-manager/SKILL.md:32` is read by Item 7's vocabulary cross-check and is not a mutation target; a local edit there changes what `adr-status-bogus` means without any porcelain entry the narrower rule would see. The critic's cost objection is satisfied anyway — measured porcelain is 30 entries, all under `.plans/`, none a read path.
2. **`heading-renamed`'s target — all three reviews assume `plugins/steps/skills/steps/SKILL.md`.** Overruled on evidence: `~/.claude/skills/steps → ~/.agents/skills/steps → plugins/steps/skills/steps` and `~/.claude/skills/pcp → ~/.agents/skills/pcp → plugins/pcp/skills/pcp` (both verified by `ls -la`), so a sweep would rewrite the live protocol document sixteen times per run.
